# riscv-lite-processor
5-stage pipelined RISC-V (RV32I subset) processor in SystemVerilog that runs compiled C through variable-latency memories over an OBI-style request/ready protocol. Full ASIC flow: Synopsys DC synthesis at 641 MHz and Cadence Innovus place &amp; route on NanGate 45 nm, plus OpenRAM SSRAM integration.
